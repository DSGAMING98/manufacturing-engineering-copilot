# Release notes

## 0.9 — observed-data prototype

- Established UCI Steel Plates Faults and UCI SECOM as the only active
  manufacturing training datasets.
- Added reproducible download, hashing, training, selection and locked-test code.
- Added a deployable 300-tree steel-fault classifier to the public website.
- Added complete machine-readable metrics, confusion matrices and source licenses.
- Removed obsolete datasets, training charts and legacy experiment runs.
- Updated the README, model card, project report and paper-readiness assessment.
