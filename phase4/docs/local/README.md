# Your authorized local documents

Put permission-cleared UTF-8 `.md` or `.txt` files here, and register each file with `python -m phase4.add_document`.
Do not add copyrighted manuals or proprietary records unless you have permission to store and process them.
Do not add actual sensitive personal, customer, equipment, or manufacturing secrets to a public repository.
A file's `approved` status must reflect a real, documented human review, not the software's opinion.
The SHA-256 in the manifest is an integrity fingerprint, not an authenticity or engineering approval certificate.
